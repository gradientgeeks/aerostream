# Security Policy

The AeroStream team takes the security of our client libraries and language bindings seriously.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| `0.1.x` | :white_check_mark: |
| `< 0.1` | :x:                |

---

## Reporting a Vulnerability

**Please DO NOT report security vulnerabilities through public GitHub issues or discussions.**

If you discover a vulnerability in any AeroStream SDK (such as authentication token leakage, buffer overflow, or unhandled socket cancellation errors), report it through:

1. **GitHub Private Vulnerability Reporting**:
   - Go to the **Security** tab of `gradientgeeks/aerostream-sdk`.
   - Click **Report a vulnerability** under *Advisories*.
2. **Direct Security Email**:
   - Email: **`security@gradientgeeks.com`**
   - CC: **`uttam-mahata-cs@outlook.com`**

### Response SLA
* **Initial Acknowledgment**: Within **48 hours**.
* **Triage & Assessment**: Within **5 business days**.
* **Remediation & Patch Release**: Within **30 days**.
