ENGINEERING SYNERGY

Why Dual-Engine? Decoupling Consensus from Log I/O

Traditional single-runtime message brokers force an impossible tradeoff: JVM garbage collection jitter or complex C++ control plane maintenance. AeroStream assigns each subsystem to its optimal language runtime.

FULL-STACK STREAMING

Built for Modern Mission-Critical Architectures

AeroStream combines enterprise-grade streaming governance, multi-cloud object storage, and hardware-accelerated zero-copy execution into a single, cohesive binary.

layers

Dual-Engine Synergy

Raft consensus state machines in Go are completely decoupled from microsecond commit log disk I/O in Rust, preventing consensus latency spikes from stalling network data planes.

Architecture
sync_alt

Kafka Protocol Drop-In

Direct wire protocol support on TCP port 9092. Works instantly with kafka-python, aiokafka, Spring Kafka, librdkafka, and Confluent CLI without proxy layers.

Wire Protocol
cloud_upload

Multi-Cloud Tiered Storage

Automated rolling of closed segments to AWS S3, MinIO, Google Cloud Storage (GCS), or Azure Blob for infinite retention at low cost while keeping hot logs on local NVMe.

Tiered Storage

Built-In Schema Registry

Confluent-compatible REST endpoints for Avro, Protobuf, and JSON schemas with BACKWARD, FORWARD, and FULL compatibility validation embedded directly in the cluster controller.

Governance

In-Broker Stream Transforms

Real-time stream filtering, JSON mapping, and automated PII data masking powered by sandboxed WASM runners executing directly inside the broker without separate Flink clusters.
